Install the staged candidate locally

Run the release build first; it writes the exact tarballs listed by artifacts/release-candidate/manifest.json.

pnpm release:bootstrap:build
npm install --save-exact \
  ./artifacts/release-candidate/aeliqo-core-0.1.0-rc.1.tgz \
  ./artifacts/release-candidate/aeliqo-runtime-0.1.0-rc.1.tgz \
  ./artifacts/release-candidate/aeliqo-web-0.1.0-rc.1.tgz \
  ./artifacts/release-candidate/aeliqo-agent-0.1.0-rc.1.tgz \
  ./artifacts/release-candidate/aeliqo-devtools-0.1.0-rc.1.tgz \
  ./artifacts/release-candidate/aeliqo-react-0.1.0-rc.1.tgz

This is a checked-out-source fallback for the staged candidate. npm publication and registry availability are not claimed.
