## Workflow

Select one catalog need backed by a user task; check whether an existing component, variant or recipe already fulfills it. Complete the component spec template: minimal input, accepted semantics, state ownership, typed ports, variants, fallback and forbidden shortcuts. Reuse audited accessible control behavior while keeping Aeliqo visuals and contracts consistent.

Build explicit standalone use first, then shared semantic binding and optional adaptive/agent-directed control using the same implementation. Preserve identity, drafts and selection across variants. D3 can calculate geometry; React owns its DOM/SVG subtree. Load heavyweight visual paths only through measured optional entry points.

Verify loading, empty, error, partial, stale, permission-denied, long labels, narrow container, reduced motion, RTL and keyboard behavior. Add a runnable documentation example from the same source, not disconnected mock markup. Inspect real screenshots/traces when available; polished typography and whitespace cannot hide semantic errors. Measure bundle and interaction change against the previous baseline.

## Completion evidence

Component contract and source; positive/negative tests; real visual/a11y evidence; runnable docs; fallback; measured package/performance delta; no unsupported perfection claim.

Report checks actually executed and their results. A schema, plan, screenshot, or mocked adapter proves only its own scope. Preserve user changes and record concrete blockers without inventing completion.
