# 34 — Work orders for implementation agents

## Start/reconcile

Use PROMPT-START.md for a fresh tree; PROMPT-RESUME.md for an interrupted implementation. Master consolidation supersedes the old kit plus separate revalidation. Never extract over an active worktree without a review branch/diff. scripts/bootstrap.py refuses nonempty targets. scripts/publish_git.py creates one new remote branch only after --apply using local authorized credentials.

## One task packet

Parent supplies task ID, frozen dependency commits, acceptance vectors, owned paths/worktree, relevant docs (not the full compiled blueprint), effective model/effort, allowed tools, test commands, expected source-bound evidence, stop conditions and integration contact. Child returns commit/diff, commands/outcomes, regressions, open risks and exact follow-up. No unverified claim of agent spawning or model changes.

## Required early sequence

1. M0 locks actual toolchain and proves shared renderer feasibility through native input/table/plot, React/vanilla/Vue embedding, SSR/hydration and forms/focus. Browser/provider access limitations are explicit.
2. T03/T04/T05 close canonical contracts and meaning, including unknown measurement, typed events, versioned function refs, exact/estimated counts, named outputs and queryless tasks.
3. T06–T11 prove data/executor/results/transactions/typed interactions. Reuse independent oracle fixtures, not prompt-specific routes.
4. T39 binds these to the actual initial UI components and stages/evaluates/presents named outputs. Prove no-preset composition, selected detail and a stale proposal. This is real product code to extend, not a throwaway demo engine.
5. Extend through every required component and full compiler. T40 adds real-provider smartness/claim evaluation; full release quality follows the task DAG.

## Scope packets by role

Semantics/query: grain/units/null/temporal/operators/fanout and independent oracles. Runtime: read-set commits, cancellation, leases, output DAG, interaction/draft ownership and inference/egress scope. Web: native controls, shared behavior, actual pixel/AT/form/SSR proof. Presentation: pattern-assisted bounded composition, task operation coverage, stable alternatives and search exhaustion. Agent: propose/evaluate/inspect/present loop, context continuity, evidence-grounded claims and no mandatory nested LLM. Docs/Studio: same manifests, compiled examples, progressive onboarding and truthful support matrix. Release: source/artifact identity, isolated consumers, staged npm/site promotion and rollback.

## Review and quality

Independent reviewer did not author the change. Contracts/schema/test registry/lockfile are orchestrator-owned. Review concrete behavior and counterexamples, not only style. A release cannot be unlocked by changing status JSON or lowering test thresholds. Missing production environment or human review becomes a precise blocked gate; finish independent work.

## Atomic commits

One commit contains a coherent behavior, relevant regression tests and docs. A multi-file contract change is one behavior; a pile of unrelated formatting fixes is not. Do not force-push an existing branch or replace main before release. Register source changes before obtaining candidate evidence so its digest remains meaningful. Test-source changes invalidate evidence just as product-source changes do.

## End report

Report specification/implemented/reference-tested/product-tested/live-provider/published/deployed/blocked separately. Include tree/SHA, artifact hashes, versions, real routes and passed/failed commands. Never call an implementation kit or a scaffold production-complete.

## Master-specific packets

Every contract/agent packet names MASTER-SOT.md and docs/37-model-failure-containment.md. T41 owns production binder/grant/failure paths, not a substitute LLM truth detector. Site/docs packets include docs/38-public-site-docs-playground.md and actual built snippet checks. T42 owns registry/version reset evidence, not destructive cleanup. Workers report residual risks and actual commands; main integrates ownership/schema/lockfile changes atomically.
