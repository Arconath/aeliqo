# ADR 004-meaning: One typed derived-meaning definition

Status: Accepted.

## Decision

AI and manual authoring produce the same typed expression/dependency representation. Business validation, activation authority and expression type validity are separate. Explicit session hypotheses need a labeled policy; an AI draft is not organizational truth.

## Consequences

Acceptance depends on the applicable implementation tasks and evidence in docs/20-execution-plan.md. This ADR is a design decision, not a claim of completed code. A replacement needs explicit alternatives, migration and conformance tests.
