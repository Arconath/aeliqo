# ADR 007-oss: Complete runtime and required catalog remain Apache-2.0

Status: Accepted as product boundary.

## Decision

Do not charge for basic security, accessibility, protocols, components or ordinary local Studio. Separate proprietary managed organizational collaboration/governance/support may consume public OSS contracts. Enterprise-capable hooks stay OSS.

## Consequences

Acceptance depends on the applicable implementation tasks and evidence in docs/20-execution-plan.md. This ADR is a design decision, not a claim of completed code. A replacement needs explicit alternatives, migration and conformance tests.
