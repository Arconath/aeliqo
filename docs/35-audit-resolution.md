## Explicit truth boundary

Reference TS is a contract prototype with a bounded subset of runtime guards. It is not the canonical whole-SDK validator. The Python planner experiment checks optional composition and search accounting over trusted manifests; it does not prove spatial layout, DOM, a11y, or graph interaction correctness. Numerical probes validate independent mathematical counterexamples, not the new TypeScript query engine. Real provider and browser acceptance remain blocked/planned until actually run.

Original 57 harness tests are retained, with additional regressions. Test counts and execution logs are reported only after running in [VALIDATION](../VALIDATION.md). No GitHub/npm/deployment change is part of the consolidation.

## Exit from repeated brainstorming

Do not add another generic engine merely to sound revolutionary. A proposal is accepted only with a counterexample showing the existing boundary cannot serve a required task, the minimal change resolving it, explicit compatibility impact and regression evidence. Closed spec findings are reopened only by such evidence. Unimplemented product gates are not silently relabeled closed.
