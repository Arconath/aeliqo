# 0.6.0 performance reference review

The reviewed reference is `9144e93fd011d985123d7357d02a37ef81144b88`.
[The exact-source probe](https://github.com/Arconath/aeliqo/actions/runs/36278132456)
completed three alternating pairs (baseline/candidate, candidate/baseline,
baseline/candidate) using the same source for both labels. This establishes
reference stability under the recorded workload and environment. It does not
establish a speedup over a previous version or capacity on other machines.

The performance-probe artifact is `10917737842`, SHA-256
`0125f921248b6f5d7b37bcb88b08b6edce75eec0ca4c4eef4d32347d84d4b27d`.
Its complete report preserves the raw timings, traces, source manifests,
environments and every observation. Independent review checked all twelve
layout/2D reports, all six absolute-budget results, source-byte guards and
relative calculations. No samples were removed and no budgets were changed.

| Pair | Baseline planner p95 | Candidate planner p95 |
| ---- | -------------------: | --------------------: |

| 2    |              14.9 ms |               14.8 ms |
| 3    |              14.9 ms |               14.6 ms |

All six planner p95 values satisfy the existing 16 ms limit. Reducer p95 is
0.4–0.5 ms against 4 ms; each large-table observation mounts 44 rows against 100. Trace phases are present. A 17.5 ms individual planner observation remains
in the raw data; the policy measures the p95 of all 30 subsequent samples.

Median layout-event p95 is 4.069 versus 3.963 ms. Median 2D mutation/layout p95
is 45.6 versus 45.8 ms. Both satisfy the reviewed relative policy: a regression
must exceed both 20% and 2 ms over the three-pair median. These metrics do not
replace the absolute planner, reducer and mounted-row limits.

Earlier probes are retained as diagnostic history: source `4da898e` exceeded
the planner budget at 19.1 ms, and source `8d581588` exceeded it at 16.2 ms in
its final candidate observation. Those probes did not pass. The subsequent
patch also fixes complete result-lineage identity and reduces temporary
allocations. Separate cross-source timing was mixed; this review makes no causal
latency claim for that patch.

Approval of this reference enables the comparison gate. The final release
source must still pass that gate and the complete same-SHA push quality run.
A diagnostic probe alone cannot authorize publication.
