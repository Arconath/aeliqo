# ADR-003 — Adaptive behavior preserves meaning and identity

Status: proposed for local reconciliation; product invariants reflect user direction. Date: 6 September 2026.

Use hard constraints then deterministic preference selection. Pins, focus, drafts, selection and reading order survive adaptation. A presentation change cannot secretly become a data-grain/currency/business-action change. Stress-test resize while editing.

Acceptance: record implementation paths and actual evidence in current-state/exec plan before marking implemented.
