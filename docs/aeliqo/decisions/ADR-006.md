# ADR-006 — No universal query engine or microservice graph

Status: proposed for local reconciliation; product invariants reflect user direction. Date: 6 September 2026.

DataPort advertises execution capability and app owns data. Core validates semantics and delegates expensive domain queries. Existing local transforms remain small/bounded. Add Workers/server features only when measured work requires them.

Acceptance: record implementation paths and actual evidence in current-state/exec plan before marking implemented.
