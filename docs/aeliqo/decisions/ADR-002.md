# ADR-002 — Portable contracts, trusted extension registry

Status: proposed for local reconciliation; product invariants reflect user direction. Date: 6 September 2026.

Keep ergonomic developer authoring distinct from safe serializable wire specs. Generate types/validators from one source; validate business semantics separately. Custom code is registered by developers, never supplied as agent executable strings. Preserve PoC contracts that satisfy these invariants.

Acceptance: record implementation paths and actual evidence in current-state/exec plan before marking implemented.
