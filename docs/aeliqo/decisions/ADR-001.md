# ADR-001 — Own components, 2D, React-first

Status: proposed for local reconciliation; product invariants reflect user direction. Date: 6 September 2026.

Ship useful components ourselves; keep core framework-neutral and effects behind ports. D3 modular geometry, no Three.js scope. Test a standalone component and a headless core consumer. Revisit 3D only after explicit product demand and a separate design.

Acceptance: record implementation paths and actual evidence in current-state/exec plan before marking implemented.
