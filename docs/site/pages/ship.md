<p class="lead">Prove the packaged product before you publish it. Run every applicable check below against the same source revision.</p>
<h2>Packages and contracts</h2><div class="doc-checklist"><ul><li>Install all five public tarballs in clean Vanilla, React, Vue, and Next.js consumers, including server rendering and hydration.</li><li>Check that invalid intents, unknown fields, unregistered views, stale revisions, and unsupported query operations fail with a bounded outcome.</li><li>Exercise data limits, authorization changes, cancellation, pagination, and action confirmation through success and failure paths.</li></ul></div>
<h2>Site and components</h2><div class="doc-checklist"><ul><li>Generate one page, live example, and component route for every active catalog ID. The inventory gate enforces exact set equality.</li><li>Mount every example and verify search, links, and route fallback behavior.</li><li>Test 360, 768, and 1440 pixel layouts. Check keyboard, focus, reduced motion, forced colors, 200% text, 400% reflow, long labels, and right-to-left text.</li><li>Scan representative journeys for serious and critical accessibility issues. Review screen-reader flows for docs, previews, playground, and action confirmation.</li><li>Compare route bundles with the previous baseline and keep layout shift below the agreed budget.</li></ul></div>
<h2>Release and cutover</h2><ol class="doc-steps"><li><span>1</span><div><h3>Build one candidate</h3><p>Build the release candidate from the final commit.</p></div></li><li><span>2</span><div><h3>Pass every check</h3><p>Run package, documentation, browser, accessibility, performance, container, and health checks on that revision.</p></div></li><li><span>3</span><div><h3>Publish and deploy</h3><p>Publish the five packages and deploy the immutable site image from the same revision.</p></div></li><li><span>4</span><div><h3>Keep rollback ready</h3><p>Retain the previous site image for rollback. Correct an already-published npm package with a patch release.</p></div></li></ol>
