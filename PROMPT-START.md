# Prompt utama — tempel seluruh isi setelah judul ini ke Codex

Implementasikan Aeliqo **0.1.0** dari clean-tree foundation ini sampai seluruh scope selesai dan release dilakukan hanya setelah gates/akses yang dibutuhkan benar-benar tersedia. Ini rewrite production-purpose, bukan PoC. MASTER-SOT.md adalah otoritas produk; docs bernomor dan harness adalah rincian acceptance. Kit lama 0.10/R2, chat, dan gambar generatif tidak menjadi overlay instruksi.

Baca AGENTS.md, MASTER-SOT.md, KIT-REVISION.json, docs/20-execution-plan.md dan harness/tasks.json. Kemudian baca chapter yang relevan secara progresif. Pertahankan Catalog/Task/Result/Experience; pure core; query/result lifecycle; own styled primitives+2D; direct components; semantic compounds; adaptive/composable region; one ADC dengan local evaluator dan HTTP; shared web realization; bounded opinionated DX/designer experience; complete OSS dan bisnis terpisah. Tidak boleh dipersempit menjadi dashboard generator atau template-only engine.

Gunakan Astra Medium orchestrator dan Luna Max worker/reviewer sebanyak kapasitas efektif. Verifikasi model ID, effort, config key, spawn capacity dan setting aktif di runtime lokal. Jangan mengarang ID atau mengubah Max menjadi xhigh diam-diam. Jangan hapus global skills/plugins v3.2 atau tool provider. Satu worktree per writer dengan task ownership, orchestrator memegang contracts/root config/lockfile/task state/integrasi/release. Reviewer tidak menjadi author. Jangan spawn agent kosong atau menulis file sama paralel.

Awali pemeriksaan kit, git/remotes/working tree, actual npm namespace/version, existing deployment/GitOps, exact toolchain/dependencies dan local runtime permissions. Jalankan python3 scripts/validate_all.py; ini hanya reference/harness, bukan product test. Percobaan GitHub write dari sesi dokumentasi ditolak 403; gunakan autentikasi lokal yang sah. Foundation publisher hanya untuk branch baru yang belum ada; jangan rerun untuk menimpa progress. Target rewrite/v0.1.0-master-foundation. Rilis 0.1.0 bukan otomatis upgrade semver dari versi lama; lakukan T42 dan docs/18-release-migration.md. Published name/version yang pernah dipakai tidak dapat dihapus lalu digunakan ulang; collision adalah blocker publikasi, bukan alasan mengarang keberhasilan.

Implementasikan M0 platform proof dahulu: native controls/table/plot, vanilla/React/Vue embedding, SSR/hydration, controlled events, form association, Shadow DOM labels/focus/AT, CSP dan style isolation. Lit adalah keputusan terisolasi yang harus lolos proof, bukan dogma. Jika gagal secara produksi, gunakan ADR berisi evidence dan strategi pengganti yang tidak menduplikasi semantics/behavior perframework. Jangan klaim SSR hanya karena import tidak error.

Selesaikan canonical schemas dan kontrak operasi sebelum consumer paralel. Task mempunyai named multigrain outputs dan queryless presentation/form; fixed/live cohorts eksplisit. Bound function versions, result revisions, scope/precision/completeness, null/time/currency/grain diperiksa. Containment tree, result DAG dan typed interaction graph berbeda. Pure passes tidak fetch. Runtime mengatur cancellation/backpressure/cache/leases/transactions dan materialization demands tanpa mengubah meaning diam-diam.

**Batas AI wajib:** AI boleh memahami konteks, menginvestigasi dan mengusulkan structured task/query/meaning/registered UI composition. AI tidak diberi authority karena nama/modelscore. Grant read/evaluate/present/meaning.activate/action.execute/model.egress independen dari host; tidak ada observe→act tangga privilege otomatis. Binder mengeluarkan bound/needs-choice/needs-meaning/unsupported/denied/invalid/stale. AI payload tidak boleh self-approve, spoofhuman, loadcode/remoteURL, bypasspermission, atau mengubah rule domain. docs/37-model-failure-containment.md wajib diimplementasikan T41.

Bedakan malformed/unknown/forbidden proposal dari valid-but-wrong interpretation. Validator tidak membaca pikiran user; klarifikasi hanya ambiguity material atau pakai documented default dengan disclosure. Model buruk tidak boleh merusak state/pixel/data contract yang telah divalidasi, tetapi jangan menjanjikan zero hallucination atau bahwa setiap valid UI menjawab pertanyaan benar. Manual/AI authoring menghasilkan representation sama; session hypothesis tidak menyamar menjadi domain truth. Observe/inspect tidak otomatis publishchart. Stop loop pada budget/no-progress/cancel; fingerprint berasal runtime termasuk scope/sourceversion. Preserve last valid authorized UI, clear revoked data. Claim AI termasuk title/tooltip harus sesuai evidence dan unit; model explanation tetap inference kecuali pemeriksaan mendukung.

Buktikan T39 raw-data-to-interaction sebelum investasi katalog luas, tanpa prompt-specific endpoint atau handler. Lanjutkan semua **71 komponen** lengkap: real code/typed API, controlled state, loading/empty/error/partial, direct imports, dark/light/contrast, keyboard/touch/IME, focus/zoom/RTL, docs, visual and package evidence.
