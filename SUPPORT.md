# Support and maturity

The repository contains the 0.1.0 source rewrite while its release is being qualified. Source behavior, package publication, browser/provider evidence, and production deployment are tracked separately. Use docs/26-observations.md and the immutable release evidence to determine what was actually verified; source presence is not a registry or deployment claim.

GitHub Issues are disabled on the public repository as of September 10, 2026. No monitored public support queue or response time is promised. Documentation, bug reports, and reproducible synthetic examples must avoid sensitive data. Security reports use the private channel in [SECURITY.md](SECURITY.md). Commercial support is a possible future offering until an actual agreement exists.
